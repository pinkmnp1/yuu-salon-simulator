# ゆうサロンスキャナー 1時間おき自動価格更新パック（24時間監査）

買取商店・家電市場・買取ルデヤの公開ページから、1時間おき（毎時00分・日本時間・24時間）に最新の
**新品・未開封の買取額**を取り直し、`scan_db.json` を書き換えて GitHub Pages に公開します。
アプリ（`index.html`）は公開URLで開いた時だけ `scan_db.json` を読みに行くので、
**アプリを開くだけで常に最新の価格**になります（内蔵DBはオフライン時の控えとして残ります）。

## アップロードするファイル（このフォルダの中身をそのまま）

```
index.html                              … アプリ本体（salon_tools/index.html と同じ）
scan_db.json                            … 価格データ（初回は今日時点の 7,678件）
scripts/update_prices.py                … 価格を取り直すプログラム
.github/workflows/update-prices.yml     … 1時間おきに動かす設定
.nojekyll                               … Pages のおまじない（空ファイル）
README.md                               … この説明（公開されても問題なし）
```

`index.html` と `scan_db.json` は**同じフォルダ**に置いてください（アプリが `./scan_db.json` を読みます）。

## GitHub への載せ方（初回だけ）

1. GitHub で新しいリポジトリを作る（Public 推奨。名前は `yuu-salon-scanner` など）。
2. このフォルダの中身を**フォルダ構成ごと**アップロードする（Add file → Upload files。
   `.github` と `scripts` のフォルダも入れてください）。
   - うまく上がらない時は GitHub Desktop でフォルダを丸ごとコミットするのが確実。
3. **Settings → Pages → Build and deployment → Source を「GitHub Actions」にする。**
   （ここが「Deploy from a branch」のままだと、自動更新のコミットでは Pages が再ビルドされず
   サイトが古いままになります。ワークフロー側でも検出して止めるようにしてあります。）
4. **Actions タブ →「買取価格を1時間おきに自動更新（24時間監査）」→ Run workflow** を1回押す。
   - 1回の実行はおよそ 4〜6分です（3社を全件巡回します）。
   - 緑のチェックが付けば、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが開きます。
5. 以降は毎時00分（日本時間）に自動で走ります（GitHub の混雑で数分〜十数分遅れることがあります）。
   価格データのコミットは1日1回（日本時間10時台）＋手動実行時だけで、
   毎時の実行は公開（Pages）だけを更新します（リポジトリに毎時2MBのJSONを積まないため）。

## 動いているか確かめる

- アプリの買取スキャナー画面の上に「**7,6xx件・2026-11-19 10:00 JST時点の公開買取上限…・自動更新済み**」と出る。
  表示の日時は `scan_db.json` の `updated_at_jst`（日本時間・毎時の取得時刻）。
- 公開URLの `scan_db.json` の `updated_at_jst` が1時間以内になっている。
- リポジトリの `scan_db.json` の更新日が今日になっている（コミット「価格を自動更新 YYYY-MM-DD」は1日1回）。
- Actions タブの実行履歴が緑。

## 中で何をしているか

| 店 | 取るもの | 備考 |
|---|---|---|
| 買取商店 | 公開API `/api/v1/products`（robots.txt で明示許可） | 全件（約6,900件）を毎回取得 |
| 家電市場 | 公開一覧の商品カード（新品価格） | 一覧にJANが無いので、DBに無い新商品だけ詳細ページでJANを確認（1回40件まで） |
| 買取ルデヤ | カテゴリ別価格表の「新品」 | 全63カテゴリ |

- 取得できた店だけを更新します。1社落ちても前回の額を消さず、残りで更新して公開します
  （3社すべて失敗した時だけ止まり、`scan_db.json` は書き換えません）。
- 価格は「各社のうち最高額」を採用し、15社ボタンには分かっている社の額を全部出します。
- 買取商店の全件巡回が成功した時だけ「載っていない＝掲載終了」と判断して、その社の額を外します。
  家電市場・買取ルデヤは部分的な巡回なので、前回の額は消しません。
- 手で調べた他店の額（携帯空間・ゲオなど）はそのまま残します。

## 手元で試す

```bash
python3 scripts/update_prices.py --dry-run        # 取得して差分を見るだけ（書き換えない）
python3 scripts/update_prices.py                  # 実際に scan_db.json を書き換える
python3 scripts/update_prices.py --source rudeya --limit 3   # 1社だけ・3ページだけ（動作確認）
```

Python 3.9 以降の標準ライブラリだけで動きます（追加インストール不要）。

## つまずいた時

- **赤い×が付いた**：Actions → その実行 → ログを見る。日本語で理由が出ます。
  - 「Pages の Source が…」→ Settings → Pages を「GitHub Actions」に変えて再実行。
  - 「どの店からも取得できませんでした」→ サイト側の仕様変更か一時的な遮断。次の毎時の実行でまた試します。
- **サイトは開くが価格が古い**：開いた直後に裏で読み込むので、数秒待って再読み込み。
  アプリの表記に「自動更新済み」が無ければ `scan_db.json` の配置（index.html と同じ階層）を確認。
- **しばらく動かさないと自動実行が止まる**：GitHub は60日間リポジトリに動きが無いと
  定期実行を止めます。Actions タブで「Enable workflow」→ Run workflow を押せば戻ります
  （毎日コミットが入るので、通常は止まりません）。
- **サイトの作りが変わった**：`scripts/update_prices.py` の取得部分だけ直せば復旧します。
